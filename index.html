Core Architecture • Screen 1 of 1

Enterprise Architecture & Data Flow

Purple Keys POS combines Google Flutter with Clean Architecture and an offline-first Hive NoSQL database, ensuring sub-10ms UI responsiveness and zero downtime even during total network drops.

📱 Google Flutter 3 UI
Hardware-accelerated 60 FPS touch interface running identically across Windows terminals, Android tablets, and mobile devices.
💾 Local Hive Storage
Embedded local NoSQL database serializes catalog master data, table occupancy, and orders without relying on active network.
⚡ Reactive BLoC Streams
Unidirectional data flow guarantees predictable state management and clean separation between UI widgets and domain logic.
🔗 Oracle & SignalR Sync
ASP.NET Core REST API backed by Oracle database with two-way SignalR WebSockets for instant multi-terminal synchronization.
📋 Standard Operating Procedure (SOP)
1 Presentation layer communicates exclusively with BLoC Cubits, completely decoupled from network clients.
2 All orders and item edits persist locally in Hive NoSQL before triggering network synchronization requests.
3 Network Sentinel monitors connection quality, auto-queuing offline operations with cryptographic UUID tracking.
⚡ Google Flutter 3 ⚡ BLoC Pattern ⚡ Hive NoSQL ⚡ Dio REST ⚡ SignalR Hub ⚡ Oracle Enterprise DB
